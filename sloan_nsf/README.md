# 斯隆奖 × NSF CAREER 可视化

## 主推：交互式动画页面

**`sloan_career_viz.html`** — 单文件、无外部依赖，双击即可用浏览器打开（也可直接拖进浏览器标签页）。

它把 1,540 位同时获得斯隆奖与 NSF CAREER 的研究者画成「斯隆年份 × CAREER 年份」的散点图，鼠标一悬停就能看到每个人的两项年份、所在机构、以及谁早谁晚几年。

**动效设计**：年份从 1996 扫到 2027，每个点在**两项奖都发生之后**才淡入，因此你会看到人群沿对角线由左下向右上生长；右侧三个计数器（CAREER 在前 / 斯隆在前 / 同年）和间隔直方图同步累积。

**可以玩的地方**

| 操作 | 效果 |
| --- | --- |
| 空格 / 暂停按钮 | 暂停或继续播放 |
| 拖动进度条 | 停在任意年份 |
| 0.5× – 4× | 调速 |
| 着色：学科 / 先后 | 换一种编码看同一批数据 |
| 点击学科标签 | 剔除某学科后计数立刻重算 |
| 悬停质点 | 个人明细气泡 |

**一个值得亲手试的发现**：点掉「化学」标签，CAREER 在前的人数从 711 掉到 418，而斯隆在前变成 440 —— **总体"CAREER 更早"的印象几乎完全由化学和计算机两个大学科撑起来的**，去掉化学后结论就翻转了。

## 静态图（用于报告 / PPT）

## 为什么这样编码

- **两个年份做两个轴**，而不是把两件事挤在一条时间轴上：这样"谁在前"变成一个几何判断——看点在虚线哪一侧，比读表快得多。
- **对角线**：y = x，即两项奖发生在同一年。同年占比 21.4%，这些点直接落在线上，一眼可见"这两个奖经常在同一时间窗被同一个人拿到"。
- **点的抖动**：原始数据全是整数年份，不打散的话点会叠成网格，看不出密度。抖动幅度控制在 ±0.22 年（小于一年），不改变任何实际结论。
- **学科分色而非先后分色**（默认）：先后已经由对角线表达了，颜色腾出来承载学科信息；想看先后时再切换即可。

## 重新生成

```powershell
$env:PYTHONPATH = 'D:\NSFraw\.pylibs'
python D:\NSFraw\prep-viz.py          # 导出 people.json
python D:\NSFraw\build-viz-html.py    # 注入数据 -> sloan_career_viz.html
python D:\NSFraw\make-scatter-v2.py   # 01_scatter.png
python D:\NSFraw\make-figures.py      # 02 / 03（同时会重写旧的 01 与 04）
python D:\NSFraw\make-gif.py          # 04_animated.gif
```

注意：`make-figures.py` 会覆盖 `01_scatter.png` 和 `04_animated.gif` 为旧版本，如需保留新版请只跑 `make-scatter-v2.py` 与 `make-gif.py`。
