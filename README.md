# 熊泽泉 · 学术主页

简洁、响应式、中英文双语的静态学术主页。无需安装依赖或构建。

## 编辑

- `dist/index.html`：页面结构和中文介绍。
- `dist/app.js`：论文、项目、履历，以及英文翻译。
- `dist/styles.css`：排版、色彩、移动端与打印样式。
- `dist/assets/portrait.jpg`：原个人主页照片。

## 使用

将 `dist/` 目录内的文件复制到 GitHub Pages 仓库根目录即可使用。目录内文件可直接通过任意静态 Web 服务器预览。

论文列表精选展示 15 篇，并非全部论文。中文论文“来源”链接指向学校个人主页；英文论文提供 DOI 链接。论文标题保留原文，中英文切换不会翻译论文标题。
